## 0.1.0

- Initial release of the Thoth Pusher Protocol v7 WebSocket and HTTP server.
- Supports public, private, and presence channels with signed publishing.
- Includes lifecycle checks, connection limits, console commands, and official `pusher-js` compatibility coverage.
- Gracefully closes active sockets and contains asynchronous connection failures.
- Ships a self-contained operations guide in the package archive.
